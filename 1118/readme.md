# 11월 18알 수업내용

## 프롬프트 공학
ChatGPT와 같은 생성형 AI에게 원하는 결과를 얻기 위해 질문이나 명령어를 효과적으로 작성하는 기술

## 프롬프트 공학의 핵심 기법
  <기법>	              <설명>
역할 부여	        AI에게 특정 역할을 지정
구체적인 지시	    원하는 작업을 명확하게 설명
맥락 제공	        필요한 배경 정보 제공
출력 형식 지정	    표, 목록, 코드 등 결과 형태 지정
예시 제공	        원하는 답변의 예시를 보여줌
단계별 요청	      복잡한 작업을 여러 단계로 나눔

## 좋은 프롬프트 작성 방법
① 역할(Role)
너는 컴퓨터공학 전문 강사야.

② 목적(Goal)
자바의 상속 개념을 설명해 줘.

③ 맥락(Context)
나는 자바 프로그래밍을 처음 배우는 학생이야.

④ 조건(Constraints)
어려운 전문용어는 쉽게 풀어서 설명해 줘.

⑤ 출력 형식(Format)
개념 설명, 예제 코드, 실행 결과 순서로 정리해 줘.

## 호스팅(hosting)
인터넷에서 웹사이트나 서비스를 운영할 수 있도록 서버의 공간과 자원을 빌려주는 서비스
