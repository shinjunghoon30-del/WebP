# 10월 14일 수업 내용

## 1.객체의 기본 개념
현실 세계의 객체: 고유한 속성(프로퍼티)과 동작을 가짐 (예: 자동차 - 색상, 배기량, 제조사 등)
자바스크립트 객체: 여러 개의 프로퍼티(변수)와 메소드(함수)로 구성된 복합 데이터 구조
-프로퍼티 : 객체의 고유한 속성(변수)
-메소드(method): 함수

### 자바스크립트 객체의 종류
코어 객체: 자바스크립트 어디서나 사용 가능한 기본 표준 객체 (Array, Date, String, Math 등)
HTML DOM 객체: HTML 태그를 객체화하여 문서 제어
브라우저 객체(BOM): 브라우저를 제어하기 위한 비표준 객체

## 2. 자바스크립트 배열
여러 개의 원소를 연속적으로 저장하고 하나의 단위로 다루는 데이터 구조
### 생성방법
리터럴 표기법 ([]): let plots = [20, 5, 8];
Array 객체 이용: let degrees = new Array(6); 또는 let degrees = new Array();

### 특징
크기가 고정되지 않고 원소 추가에 따라 자동으로 늘어남
length 프로퍼티를 통해 배열의 크기를 알 수 있으며, 임의로 변경하여 크기를 조절 가능
다양한 타입의 데이터를 섞어서 저장할 수 있음

## 3.주요 자바스크립트 코어 객체
### date객체
시간과 날짜 정보를 다루는 객체
new Date()를 통해 현재 또는 특정 날짜/시간 객체 생성

### String객체
문자열을 다루기 위한 객체로, 한 번 생성되면 내부 문자열 내용은 수정할 수 없음
length 프로퍼티로 문자열 길이를 제공하며, 배열처럼 인덱스로 각 문자에 접근 가능 (str[0])

### Math객체
수학 계산을 위한 프로퍼티와 메소드를 제공하며, new Math()로 인스턴스를 생성하지 않고 직접 사용
주요 메소드: Math.sqrt(), Math.random() (0 이상 1 미만의 난수), Math.floor() (소수점 이하 버림) 등

## 4.사용자 정의 객체 만들기
### 자바스크립트에서 사용자가 새로운 타입의 객체를 만드는 3가지 방법
new Object() 이용: 빈 객체를 생성한 뒤 프로퍼티와 메소드를 동적으로 추가.
리터럴 표기법 ({}) 이용: 중괄호 내부에 프로퍼티와 메소드를 직접 정의하는 가장 흔히 쓰이는 방식.
프로토타입(Prototype) 이용: 객체의 모양을 찍어내는 틀(생성자 함수)을 정의하고 new 연산자로 여러 객체를 생성, 함수 내부에서 this를 사용하여 프로퍼티와 메소드를 정의함
