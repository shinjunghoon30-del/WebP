## 1. 자바스크립트(JavaScript)
### 특징
HTML 문서 내에 내장되는 스크립트 언어로, 컴파일 과정 없이 웹 브라우저의 자바스크립트 엔진에 의해 바로 실행(인터프리터)됩니다.
### 주요 역할
사용자 입력 처리 및 동적 계산 수행
HTML 콘텐츠, CSS 속성, 태그 모양 등 웹 페이지의 내용/스타일 동적 제어
브라우저 창 크기 제어, 히스토리 관리 등 브라우저 동작 제어
서버와의 통신 및 그래픽, 스토리지 등 웹 애플리케이션 기능 구현

## 2. 자바스크립트 코드 작성 및 삽입 방법
HTML 태그의 이벤트 리스너 속성: 태그 내부의 이벤트 속성(예: onclick, onmouseover)에 직접 작성.
<script> 태그 내 작성: <head>나 <body> 영역 어디에나 위치할 수 있으며 여러 번 삽입 가능.
외부 별도 파일(.js)로 작성: <script src="filename.js"></script> 형태로 불러와 코드 중복을 방지하고 재사용.
URL 위치(href 속성)에 작성: <a href="javascript:code"> 형태로 작성
