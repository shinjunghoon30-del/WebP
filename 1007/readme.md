# 10월7일 수업내용

## 1. 자바스크립트(JavaScript)
### 특징
HTML 문서 내에 내장되는 스크립트 언어로, 컴파일 과정 없이 웹 브라우저의 자바스크립트 엔진에 의해 바로 실행(인터프리터)됩니다.
### 주요 역할
사용자 입력 처리 및 동적 계산 수행
HTML 콘텐츠, CSS 속성, 태그 모양 등 웹 페이지의 내용/스타일 동적 제어
브라우저 창 크기 제어, 히스토리 관리 등 브라우저 동작 제어
서버와의 통신 및 그래픽, 스토리지 등 웹 애플리케이션 기능 구현

## 2. 자바스크립트 코드 작성 및 삽입 방법
HTML 태그의 이벤트 리스너 속성: 태그 내부의 이벤트 속성(예: onclick, onmouseover)에 직접 작성.
<script> 태그 내 작성: <head>나 <body> 영역 어디에나 위치할 수 있으며 여러 번 삽입 가능.
외부 별도 파일(.js)로 작성: <script src="filename.js"></script> 형태로 불러와 코드 중복을 방지하고 재사용.
URL 위치(href 속성)에 작성: <a href="javascript:code"> 형태로 작성

## 3. 입출력 및 사용자 다이얼로그
## 콘텐츠 출력
document.write() / document.writeln(): 웹 페이지 화면에 HTML 콘텐츠를 직접 출력
## 다이얼로그 함수
prompt("메시지", "기본값"): 사용자로부터 문자열을 입력받아 반환 (취소 시 null 반환)
confirm("메시지"): [확인/취소] 버튼을 통해 true 또는 false 반
alert("메시지"): 경고 메시지와 [확인] 버튼을 가진 알림창 출력

## 4. 식별자, 데이터 타입, 변수 및 상수
### 식별자 및 문장
식별자 규칙: 첫 글자는 영문자, _, $만 가능하며, 대소문자를 구분하고 예약어(if, for 등)는 사용할 수 없음
문장 구분: 문장 끝에는 세미콜론(;)을 사용함
### 데이터 타입
숫자(정수/실수), 논리(true/false), 문자열, 객체 레퍼런스, null 등이 존재함

### 변수(Variable) 선언 및 범위
#### 선언 키워드
var: 기존 키워드로, 변수 재선언이 가능하여 실수의 여지가 있음
let: ES6에서 도입되었으며, 동일한 변수의 재선언을 금지하고 블록 범위를 가짐 (권장)
const: ES6에서 도입된 상수를 선언하는 키워드로, 선언 후 값 변경 및 재선언 불가 
#### 유효 범위
전역 변수: 함수 밖에서 선언되거나 키워드 없이 선언되며, 프로그램 전체에서 유효
지역 변수: 함수 내에서 선언되며 해당 함수 내에서만 유효
블록 변수: let으로 if, for 등의 블록 내에서 선언되며 해당 블록 내에서만 유효

## 5. 연산자
산술 연산자: +, -, *, /, % (나누기 결과는 항상 실수)
증감 연산자: ++, -- (전위형과 후위형의 반환 시점이 다름)  
대입 연산자: =, +=, -=, *=, /=, %= 등
비교 연산자: >, <, >=, <=, ==, != (결과는 true/false) 
논리 연산자: && (AND), || (OR), ! (NOT)
조건 연산자: 조건식 ? 참일 때 값 : 거짓일 때 값 
비트 연산자: 비트 논리(&, |, ^, ~) 및 비트 시프트(<<, >>, >>>) 연산  
문자열 연산자: + 연산자로 문자열 연결 가능

## 6. 제어문 및 반복문
### 조건문
if / if-else / else if: 조건식의 참/거짓에 따라 실행 흐름 제어
switch: 식의 결과 값에 따라 해당 case 문 실행. 
case 조건 값으로는 리터럴이나 const 상수만 사용 가능 (변수나 식 사용 불가)
break 문이 없으면 다음 case로 계속 흘러내려 실행됨
### 반복문 및 흐름 제어
for, while, do-while: 조건에 따라 코드 블록을 반복 실행
break: 현재 속한 가장 안쪽의 반복문 1개를 완전히 탈출
continue: 현재 반복을 중단하고 다음 반복 검사/증감식 단계로 점프

## 7. 함수(Function) 및 주요 전역 함수

function 함수이름(매개변수1, 매개변수2, ...) { ... return 결과; } 구조로 선언하고 호출하여 사용
